Four Fazi layouts, each with vertical tabs

Every mockup runs on the same engine (shared/core.js): the same fake home folder, state, commands, and keyboard map. Only the layout and styling change, so tabs, dual pane, search, Get Info, auto-cleanup, Trash, the command palette, and Vim mode behave identically in all four.

Hover a screenshot to see dual pane. Open a design to click around; the bar above each window switches designs, theme, and demo states.

Rail A

One column owns the window, as in Arc. Search sits at the top, system places become icon tiles, and open tabs fill the rest. The file list floats as an inset card, and the toolbar disappears.

Tabs
One list in the sidebar; dual pane splits it into Left and Right groups.
Path
Breadcrumbs in each card’s header.
Strength
Calmest window. The most room for long tab names.
Tradeoff
Hiding the sidebar (⌥⌘S) hides the tabs too. Opens in light theme.
Open Rail

Strip B

Today’s Fazi with the tab strip turned on its side. Each pane owns a vertical tab column, and the active tab breaks the column edge to flow into its list, as Finder’s tabs connect to their content.

Tabs
Per pane, two lines each (name, then where it lives). Folds to monograms.
Path
Toolbar breadcrumbs follow the active pane, as now.
Strength
Smallest change for existing users. Tabs stay with their pane.
Tradeoff
Three vertical bands before the list. Dual pane gets tight on small screens.
Open Strip

Trail C

Locations shrink to an icon rail so tabs get the room. The active tab unfolds into its own path, drawn as a trail from Home down to the current folder, which replaces the breadcrumb bar.

Tabs
Grouped by pane. Active tab expands; the others fold to one line.
Path
The trail inside the active tab. Double-click it to type a path.
Strength
Tab and location merge into one idea. Ancestors are easy click and drop targets.
Tradeoff
Icon-only locations rely on tooltips. Deep paths elide the top of the trail.
Open Trail

Console D

Built for the keyboard. Dense rows, a Vim-style mode line, and a command line at the bottom where the filter lives. Each pane has its own path header, and in dual pane the tab columns mirror on the outer edges.

Tabs
Compact list per pane: left pane on the left, right pane on the right.
Path
Per-pane header (~/Projects/…), plus the mode line.
Strength
Most rows on screen. Shortcuts shown next to what they open.
Tradeoff
Feels technical for mouse-first users. The amber accent is the most opinionated.
Open Console

Each palette defines one accent, so Fazi’s custom accent setting would still apply in every design. Both themes are available in all four.

Things to try in every design

  • Click tabs, middle-click to close, right-click for the tab menu
  • ⌥T new tab and ⌥W close (stand-ins for ⌘T and ⌘W, which the browser keeps)
  • ⌃⇥ next tab, or gt and gT in Vim mode
  • ⌘⇧D dual pane, ⇥ to switch panes
  • Double-click folders, ⌘[ and ⌘] back and forward, ⌘↑ up
  • Type in the filter, then ⏎ to search everywhere and change scope
  • ⌘K command palette, ⌘P go to file
  • ⌘I Get Info, ⌥⌘S sidebar, ⌘1 and ⌘2 list and icons
  • Downloads shows the auto-cleanup banner, column, and badges
  • Trash shows its banner and Empty Trash confirmation
  • Double-click the path (or ⌘⇧G) to type a location
  • j/k, v, /, :, g? with Vim mode on

Demo states also load from the URL, for example c-trail.html#split&info&theme=light, go=~/Downloads, search=notes, palette, op, or fda.
